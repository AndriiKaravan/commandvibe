# Звіт: P1 «фундамент» і каталог завдань

## Завдання (від хабу, 26.11 вечір)

«Власник додав усі redirect URIs і JS origins в OAuth-клієнт; тест входу (Chrome, Safari, Telegram, Instagram, Viber) — завтра. До того працюй автономно:
1) Почни реалізацію P1 (foundation) за планом у гілці; TDD, рев'ю; злиття в main і пуш — за постійним дозволом хабу (зелені тести + рев'ю без блокерів).
2) Контент: каталог перших завдань дня — щонайменше 60 завдань по темах (офіс/колеги, студенти, друзі, сім'я з дітьми — безпечні для дітей, зима/Новий рік, вихідні, «назовні», креатив/смішні), UA + EN, з позначкою складності й «можна вдома/потрібно вийти»; без завдань, що змушують фотографувати чужих людей, документи, обличчя дітей крупно чи небезпечне. Файл у репо, показати власнику завтра.
3) Spike лишити до завтрашнього тесту.
Не робити без власника: прод-деплой, DNS, консолі, зміни ks_core/ks_server.»

## Зроблено

**Сервер (`server/`, NestJS):** репозиторії за інтерфейсами (пам'ять + Firestore, спільні контрактні тести), власні сесії з ротацією токена оновлення, вхід організатора через Firebase ID token, групи й посилання-запрошення (лише SHA-256), приєднання за посиланням з необов'язковим підтвердженням, PIN (argon2, 5 помилок → 15 хв), дії організатора, сторінка запрошення `/j/:token` з OG-тегами, realtime (ks_server v0.3.0) з правами на теми, App Check guard (ks_core v0.6.2) у режимі `monitor`, тестовий маршрут лише для `NODE_ENV=test`. Тести: 203 unit + 28 e2e.

**Застосунок (`app/`, Flutter Web + Android + iOS):** абстракції платформ, `ApiClient` зі спільним refresh, realtime-клієнт ks_core, тема «Скло» (токени з макетів E/E2) з запасним варіантом без розмиття, екрани: вітання, вхід організатора (Google), створення групи й поширення запрошення, приєднання, PIN, повернення з PIN, головна групи з живим списком учасників. UA + EN. 42 тести; збірки web, apk, iOS-симулятор — зелені.

**Наскрізна перевірка одного сценарію** (посилання → ім'я → PIN → головна → новий учасник з'являється наживо): ✅ веб (headless Chrome, `tool/e2e_web.mjs`), ✅ iOS-симулятор, ✅ Android-емулятор (`app/integration_test/join_flow_test.dart`).

**Контент:** каталог 76 завдань (UA + EN, теми, для кого, складність, вдома/назовні) — `server/src/content/task-catalog.ts`, таблиця для власника — `docs/content/task-catalog-v1.md`; правила безпеки перевіряє тест.

**Firebase:** зареєстровано Android- і iOS-застосунки в `commandvibe-ks` (рівень flutterfire configure), опції — у Dart.

**Деплой:** `server/Dockerfile`, `tool/deploy_api.sh` (ревізія `candidate`), `tool/deploy_web_preview.sh`, порядок — `docs/deploy.md`. Нічого не розгорнуто.

- Локальна збірка Docker-образу не перевірена (Docker не запущено).
