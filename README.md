# CommandVibe

Групова гра «фото-челендж» для закритих груп (колеги, студенти, друзі, сім'я): щодня нове завдання, учасники підтверджують його фото, чужі фото розмиті до власного виконання або до автоматичного розкриття через 2 дні. Бали, рейтинг наживо, фінал із колажем.

- **Адреса (план):** https://commandvibe.karavanstudio.dev (Flutter Web, PWA)
- **Стек (план):** Flutter Web + Node.js (NestJS) з REST і WebSocket, Firebase (Firestore, Storage)
- **Статус:** дизайн на погодженні власником, коду ще немає
